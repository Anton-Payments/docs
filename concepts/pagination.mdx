## Overview

All list endpoints return paginated results. The Anton API uses **cursor-based pagination** with `limit` and `cursor` query parameters.

## Parameters

| Parameter | Type | Default | Max | Description |
|-----------|------|---------|-----|-------------|
| `limit` | integer | 20 | 100 | Number of items to return |
| `cursor` | string | — | — | Opaque cursor from a previous response. Omit to start from the beginning. |

## Response format

Every list response includes a `has_more` boolean. When `has_more` is `true`, a `next_cursor` string is also present:

```json
{
  "data": [
    { "id": "pay_abc123", "status": "completed", "amount": "500.00" },
    { "id": "pay_def456", "status": "processing", "amount": "1200.00" }
  ],
  "has_more": true,
  "next_cursor": "pay_def456"
}
```

| Field | Description |
|-------|-------------|
| `data` | Array of results for this page |
| `has_more` | `true` if more results exist beyond this page |
| `next_cursor` | Cursor to pass in the next request. Only present when `has_more` is `true`. |

When you reach the last page, `has_more` is `false` and `next_cursor` is not included:

```json
{
  "data": [
    { "id": "pay_xyz789", "status": "completed", "amount": "300.00" }
  ],
  "has_more": false
}
```

## Iterating through pages

Pass the `next_cursor` value from each response as the `cursor` parameter in the next request:

<CodeGroup>

```bash cURL
# First page
curl "https://api.antonpayments.dev/v1/payouts?limit=20" \
  -H "Authorization: Bearer ak_test_..."

# Next page (using next_cursor from previous response)
curl "https://api.antonpayments.dev/v1/payouts?limit=20&cursor=pay_def456" \
  -H "Authorization: Bearer ak_test_..."
```

```javascript Node.js
async function getAllPayouts(apiKey) {
  const payouts = [];
  let cursor = undefined;

  while (true) {
    const url = new URL('https://api.antonpayments.dev/v1/payouts');
    url.searchParams.set('limit', '100');
    if (cursor) {
      url.searchParams.set('cursor', cursor);
    }

    const response = await fetch(url, {
      headers: { Authorization: `Bearer ${apiKey}` },
    });
    const json = await response.json();
    payouts.push(...json.data);

    if (!json.has_more) break;
    cursor = json.next_cursor;
  }

  return payouts;
}
```

```python Python
import requests

def get_all_payouts(api_key):
    payouts = []
    cursor = None

    while True:
        params = {"limit": 100}
        if cursor:
            params["cursor"] = cursor

        response = requests.get(
            "https://api.antonpayments.dev/v1/payouts",
            headers={"Authorization": f"Bearer {api_key}"},
            params=params,
        )
        data = response.json()
        payouts.extend(data["data"])

        if not data["has_more"]:
            break
        cursor = data["next_cursor"]

    return payouts
```

```go Go
func getAllPayouts(apiKey string) ([]Payout, error) {
	var payouts []Payout
	cursor := ""

	for {
		url := "https://api.antonpayments.dev/v1/payouts?limit=100"
		if cursor != "" {
			url += "&cursor=" + cursor
		}

		req, _ := http.NewRequest("GET", url, nil)
		req.Header.Set("Authorization", "Bearer "+apiKey)

		resp, err := http.DefaultClient.Do(req)
		if err != nil {
			return nil, err
		}

		var result struct {
			Data       []Payout `json:"data"`
			HasMore    bool     `json:"has_more"`
			NextCursor string   `json:"next_cursor"`
		}
		json.NewDecoder(resp.Body).Decode(&result)
		resp.Body.Close()

		payouts = append(payouts, result.Data...)

		if !result.HasMore {
			break
		}
		cursor = result.NextCursor
	}

	return payouts, nil
}
```

## Tips

<AccordionGroup>
  <Accordion title="Use the maximum page size">
    Set `limit=100` to minimize the number of API calls when fetching all items.
  </Accordion>
  <Accordion title="Stop when has_more is false">
    The `has_more` field tells you whether another page exists. When it is `false`, you have reached the end of the result set.
  </Accordion>
  <Accordion title="Cursors are opaque">
    Treat cursor values as opaque strings. Do not parse, modify, or construct them. Always use the exact `next_cursor` value returned by the API.
  </Accordion>
  <Accordion title="Cursors do not expire">
    Cursor values remain valid indefinitely. You can store a cursor and resume pagination later.
  </Accordion>
</AccordionGroup>
