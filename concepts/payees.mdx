## Overview

A **payee** is the recipient of a payout. You create a payee once with their identity and payment details, then reference them by ID whenever you send a payout.

Payees can be:
- **Individuals** — a person receiving funds (freelancer, contractor, customer refund)
- **Businesses** — a company receiving funds (supplier, vendor, partner)

## Creating a payee

<CodeGroup>

```bash Individual
curl https://api.antonpayments.dev/v1/payees \
  -X POST \
  -H "Authorization: Bearer ak_test_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: create-payee-jane-smith" \
  -d '{
    "type": "individual",
    "first_name": "Jane",
    "last_name": "Smith",
    "email": "jane@example.com",
    "country": "GB",
    "currency": "GBP",
    "bank_account": {
      "account_number": "12345678",
      "sort_code": "123456"
    }
  }'
```

```bash Business
curl https://api.antonpayments.dev/v1/payees \
  -X POST \
  -H "Authorization: Bearer ak_test_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: create-payee-acme-corp" \
  -d '{
    "type": "business",
    "company_name": "Acme Corp",
    "email": "payments@acme.com",
    "country": "US",
    "currency": "USD",
    "bank_account": {
      "account_number": "9876543210",
      "routing_number": "021000021"
    }
  }'
```

</CodeGroup>

## Payment details

Payees need payment routing information. The required fields depend on the destination country and rail:

| Country/Rail | Required Fields |
|-------------|----------------|
| **US (ACH)** | `account_number`, `routing_number` |
| **UK (FPS)** | `account_number`, `sort_code` |
| **EU (SEPA)** | `iban` |
| **International (SWIFT)** | `iban` or `account_number`, `swift_code` |

## Instruments

For payees that receive payments through multiple methods (e.g., bank account and mobile wallet), you can attach multiple **instruments** to a single payee. See the [Instruments API](/api-reference/instruments/create-instrument-for-payee) for details.

## Payee verification

In production, payees undergo compliance screening when first used in a payout. This includes:

- **Name matching** — Verifying the name matches the bank account holder
- **Sanctions screening** — OFAC, PEP, and global sanctions list checks
- **Country checks** — Ensuring the destination country is not blocked

<Info>
  Payee screening happens automatically during payout creation. You don't need to call a separate verification endpoint.
</Info>

## Listing payees

Retrieve all payees with cursor-based pagination:

```bash
curl "https://api.antonpayments.dev/v1/payees?limit=20" \
  -H "Authorization: Bearer ak_test_..."
```

To fetch the next page, pass the `next_cursor` value from the previous response:

```bash
curl "https://api.antonpayments.dev/v1/payees?limit=20&cursor=pye_def456" \
  -H "Authorization: Bearer ak_test_..."
```

See [Pagination](/concepts/pagination) for details.

## Deleting payees

<Warning>
  Deleting a payee is permanent. Any pending payouts to this payee will still complete, but you won't be able to create new payouts to them.
</Warning>

```bash
curl https://api.antonpayments.dev/v1/payees/pye_abc123 \
  -X DELETE \
  -H "Authorization: Bearer ak_test_..."
```
