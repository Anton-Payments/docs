## Overview

This guide walks through the full payout lifecycle: checking your balance, creating a payee, adding a payment instrument, sending the payout, and tracking its status through to completion.

## Prerequisites

- An Anton Payments account with [API keys](/authentication)
- Funded [balances](/concepts/balances) in the source currency (sandbox has test balances pre-loaded)

## 1. Check your balance

Before sending a payout, verify you have sufficient funds:

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/balances/USD \
  -H "Authorization: Bearer ak_test_..."
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/balances/USD", {
  headers: {
    "Authorization": "Bearer ak_test_...",
  },
});

const { data: balance } = await response.json();
console.log(`Available: ${balance.available}`);
```

```python Python
import requests

response = requests.get(
    "https://api.antonpayments.dev/v1/balances/USD",
    headers={"Authorization": "Bearer ak_test_..."},
)

balance = response.json()["data"]
print(f"Available: {balance['available']}")
```

```go Go
req, _ := http.NewRequest("GET", "https://api.antonpayments.dev/v1/balances/USD", nil)
req.Header.Set("Authorization", "Bearer ak_test_...")

resp, err := http.DefaultClient.Do(req)
```

</CodeGroup>

```json Response
{
  "data": {
    "currency": "USD",
    "available": "50000.00",
    "held": "2000.00",
    "total": "52000.00"
  }
}
```

The `available` amount is what you can use for new payouts. Ensure it covers the payout amount plus any fees.

## 2. Create a payee

If you are paying someone for the first time, create a payee record:

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/payees \
  -X POST \
  -H "Authorization: Bearer ak_test_..." \
  -H "Content-Type: application/json" \
  -d '{
    "type": "individual",
    "first_name": "Maria",
    "last_name": "Garcia",
    "email": "maria@example.com",
    "country": "US"
  }'
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/payees", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    type: "individual",
    first_name: "Maria",
    last_name: "Garcia",
    email: "maria@example.com",
    country: "US",
  }),
});

const { data: payee } = await response.json();
console.log(`Payee created: ${payee.id}`);
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.dev/v1/payees",
    headers={"Authorization": "Bearer ak_test_..."},
    json={
        "type": "individual",
        "first_name": "Maria",
        "last_name": "Garcia",
        "email": "maria@example.com",
        "country": "US",
    },
)

payee = response.json()["data"]
print(f"Payee created: {payee['id']}")
```

```go Go

    "type": "individual",

```

</CodeGroup>

```json Response

  "data": {
    "id": "pye_cng3q8s6ek9kc5qg1h1g",
    "type": "individual",
    "first_name": "Maria",
    "last_name": "Garcia",
    "email": "maria@example.com",
    "country": "US",
```

Save the `id` -- you will need it to add an instrument and create the payout.

## 3. Add a payment instrument

Attach a bank account or other payment method to the payee:

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/payees/pye_cng3q8s6ek9kc5qg1h1g/instruments \
  -X POST \
  -H "Authorization: Bearer ak_test_..." \
  -H "Content-Type: application/json" \
  -d '{
    "type": "bank_account",
    "currency": "USD",
    "details": {
      "account_number": "9876543210",
      "routing_number": "021000021"
    }
  }'
```

## 4. Send the payout

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/payouts \
  -X POST \
  -H "Authorization: Bearer ak_test_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: invoice-1042-maria" \
  -d '{
    "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
    "instrument_id": "ins_cng3q8s6ek9kc5qg1h3g",
    "amount": "2500.00",
    "currency": "USD",
    "description": "Consulting fee - January 2026",
    "reference": "INV-1042"
  }'
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/payouts", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_...",
    "Content-Type": "application/json",
    "Idempotency-Key": "invoice-1042-maria",
  },
  body: JSON.stringify({
    payee_id: "pye_cng3q8s6ek9kc5qg1h1g",
    instrument_id: "ins_cng3q8s6ek9kc5qg1h3g",
    amount: "2500.00",
    currency: "USD",
    description: "Consulting fee - January 2026",
    reference: "INV-1042",
  }),
});

const { data: payout } = await response.json();
console.log(`Payout ${payout.id} created with status: ${payout.status}`);
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.dev/v1/payouts",
    headers={
        "Authorization": "Bearer ak_test_...",
        "Idempotency-Key": "invoice-1042-maria",
    },
    json={
        "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
        "instrument_id": "ins_cng3q8s6ek9kc5qg1h3g",
        "amount": "2500.00",
        "currency": "USD",
        "description": "Consulting fee - January 2026",
        "reference": "INV-1042",
    },
)

payout = response.json()["data"]
print(f"Payout {payout['id']} created with status: {payout['status']}")
```

```go Go
body := `{
    "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
    "instrument_id": "ins_cng3q8s6ek9kc5qg1h3g",
    "amount": "2500.00",

req.Header.Set("Authorization", "Bearer ak_test_...")

req.Header.Set("Idempotency-Key", "invoice-1042-maria")

resp, err := http.DefaultClient.Do(req)
```

</CodeGroup>

```json Response
{
  "data": {
    "id": "pay_cng3q8s6ek9kc5qg1h2g",
    "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
    "instrument_id": "ins_cng3q8s6ek9kc5qg1h3g",
    "amount": "2500.00",
    "currency": "USD",
    "status": "pending_screening",
    "description": "Consulting fee - January 2026",
    "reference": "INV-1042",
    "created_at": "2026-02-14T10:02:00Z"
  }
}
```

<Tip>
  **Always include an Idempotency-Key** for payout creation. This protects against duplicate payouts if your request is retried due to network issues. Use a deterministic value like your internal invoice or transaction ID.
</Tip>

## 5. Track the payout

### Option A: Poll the status

```bash
curl https://api.antonpayments.dev/v1/payouts/pay_cng3q8s6ek9kc5qg1h2g \
  -H "Authorization: Bearer ak_test_..."
```

### Option B: Use webhooks (recommended)

Set up a [webhook subscription](/guides/handle-webhooks) to get notified automatically as the payout moves through each stage:

```
payout.created -> payout.screening -> payout.processing -> payout.sent -> payout.completed
```

## Payout lifecycle

A payout progresses through these statuses:

| Status | Description |
|--------|-------------|
| `pending_screening` | Created, awaiting compliance screening |
| `screening` | Compliance checks in progress |
| `pending_approval` | Flagged for manual review |
| `processing` | Approved, submitted to payment rail |
| `sent` | Payment rail confirmed dispatch |
| `completed` | Funds delivered to the payee |
| `failed` | Payout could not be completed |
| `returned` | Funds returned after delivery attempt |
| `cancelled` | Cancelled before processing |

## Common issues

<AccordionGroup>
  <Accordion title="Insufficient balance">
    You will get a `400` error if `available` balance is too low. Fund your account or retry when pending payouts complete and release held funds.
  </Accordion>
  <Accordion title="Invalid payee">
    Ensure the payee ID exists and belongs to your merchant account. Check you are using the right environment (sandbox vs production).
  </Accordion>
  <Accordion title="Missing instrument">
    A payout requires both a `payee_id` and an `instrument_id`. Create an instrument on the payee before submitting the payout.
  </Accordion>
  <Accordion title="Payout stuck in screening">
    In production, compliance screening can take a few seconds to a few minutes. If a payout stays in `pending_screening` for more than 10 minutes, contact support.
  </Accordion>
</AccordionGroup>
