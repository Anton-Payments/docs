## Before you begin

You'll need an Anton Payments account and an API key. If you don't have one yet, [register for a sandbox account](https://app.antonpayments.com) or contact our team.

<Info>
  **Sandbox mode** — All examples use test API keys (`ak_test_...`). No real money moves in sandbox. Switch to `ak_live_...` keys when you're ready for production.
</Info>

## Step 1: Authenticate

Every API request requires a Bearer token in the `Authorization` header. Your API key looks like `ak_test_...` (sandbox) or `ak_live_...` (production).

```bash
curl https://api.antonpayments.com/v1/merchant \
  -H "Authorization: Bearer ak_test_your_key_here"
```

<Check>
  If you get back your merchant profile, you're authenticated and ready to go.
</Check>

## Step 2: Create a beneficiary

Before you can send money, you need to register the recipient. A beneficiary stores the recipient's identity and payment details.

<CodeGroup>

```bash cURL
curl https://api.antonpayments.com/v1/beneficiaries \
  -X POST \
  -H "Authorization: Bearer ak_test_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "individual",
    "first_name": "Jane",
    "last_name": "Smith",
    "email": "jane@example.com",
    "country": "GB",
    "currency": "GBP",
    "bank_account": {
      "account_number": "12345678",
      "sort_code": "123456"
    }
  }'
```

```javascript Node.js
const beneficiary = await fetch("https://api.antonpayments.com/v1/beneficiaries", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_your_key_here",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    type: "individual",
    first_name: "Jane",
    last_name: "Smith",
    email: "jane@example.com",
    country: "GB",
    currency: "GBP",
    bank_account: {
      account_number: "12345678",
      sort_code: "123456",
    },
  }),
});

const data = await beneficiary.json();
console.log(data.data.id); // ben_cng3q8s...
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.com/v1/beneficiaries",
    headers={"Authorization": "Bearer ak_test_your_key_here"},
    json={
        "type": "individual",
        "first_name": "Jane",
        "last_name": "Smith",
        "email": "jane@example.com",
        "country": "GB",
        "currency": "GBP",
        "bank_account": {
            "account_number": "12345678",
            "sort_code": "123456",
        },
    },
)

beneficiary = response.json()
print(beneficiary["data"]["id"])  # ben_cng3q8s...
```

</CodeGroup>

Save the `id` from the response — you'll need it in the next step.

## Step 3: Send a payout

Now send money to your beneficiary. The payout goes through compliance screening and routing automatically.

<CodeGroup>

```bash cURL
curl https://api.antonpayments.com/v1/payouts \
  -X POST \
  -H "Authorization: Bearer ak_test_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "beneficiary_id": "ben_cng3q8s6ek9kc5qg1h1g",
    "amount": "250.00",
    "currency": "GBP",
    "description": "Invoice #1042 payment",
    "reference": "INV-1042"
  }'
```

```javascript Node.js
const payout = await fetch("https://api.antonpayments.com/v1/payouts", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_your_key_here",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    beneficiary_id: "ben_cng3q8s6ek9kc5qg1h1g",
    amount: "250.00",
    currency: "GBP",
    description: "Invoice #1042 payment",
    reference: "INV-1042",
  }),
});

const data = await payout.json();
console.log(data.data.id);     // pay_cng3q8s...
console.log(data.data.status); // "created"
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.com/v1/payouts",
    headers={"Authorization": "Bearer ak_test_your_key_here"},
    json={
        "beneficiary_id": "ben_cng3q8s6ek9kc5qg1h1g",
        "amount": "250.00",
        "currency": "GBP",
        "description": "Invoice #1042 payment",
        "reference": "INV-1042",
    },
)

payout = response.json()
print(payout["data"]["id"])      # pay_cng3q8s...
print(payout["data"]["status"])  # "created"
```

</CodeGroup>

## Step 4: Check the status

Poll the payout to see it progress through the lifecycle:

```bash
curl https://api.antonpayments.com/v1/payouts/pay_cng3q8s6ek9kc5qg1h2g \
  -H "Authorization: Bearer ak_test_your_key_here"
```

The payout moves through these statuses:

```
created → pending_screening → processing → sent → completed ✓
```

<Tip>
  **Don't poll — use webhooks.** Set up a [webhook subscription](/guides/handle-webhooks) to get notified instantly when payout status changes. Polling is fine for testing, but webhooks are the way to go in production.
</Tip>
