## Before you begin

You need an Anton Payments account and a sandbox API key. If you do not have one yet, [contact our team](https://antonpayments.com/contact) to get provisioned.

<Info>
  **Sandbox mode** -- All examples in this guide use the sandbox environment (`api.antonpayments.dev`) and test API keys (`ak_test_...`). No real money moves. Switch to `api.antonpayments.com` and `ak_live_...` keys when you are ready for production.
</Info>

---

## Step 1: Get your API key

API keys are created in the [merchant portal](https://app.antonpayments.com). Navigate to **Settings > API Keys** and generate a sandbox key. The key is displayed once at creation time -- save it immediately.

Your key will look like this:

```
ak_test_7f3a9b2c...
```

Test that it works by fetching your merchant profile:

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/merchant \
  -H "Authorization: Bearer ak_test_your_key_here"
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/merchant", {
  headers: {
    "Authorization": "Bearer ak_test_your_key_here",
  },
});

const { data } = await response.json();
console.log(data.id);
```

```python Python
import requests

response = requests.get(
    "https://api.antonpayments.dev/v1/merchant",
    headers={"Authorization": "Bearer ak_test_your_key_here"},
)

merchant = response.json()
print(merchant["data"]["id"])
```

```go Go
req, _ := http.NewRequest("GET", "https://api.antonpayments.dev/v1/merchant", nil)
req.Header.Set("Authorization", "Bearer ak_test_your_key_here")

resp, err := http.DefaultClient.Do(req)
```

</CodeGroup>

<Check>
  If you get back your merchant profile, you are authenticated and ready to go.
</Check>

## Step 2: Create a payee

Before you can send money, you need to register the recipient. A payee stores the recipient's identity and payment instrument details.

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/payees \
  -X POST \
  -H "Authorization: Bearer ak_test_your_key_here" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: create-payee-jane-001" \
  -d '{
    "type": "individual",
    "first_name": "Jane",
    "last_name": "Smith",
    "email": "jane@example.com",
    "country": "GB",
    "currency": "GBP",
    "bank_account": {
      "account_number": "12345678",
      "sort_code": "123456"
    }
  }'
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/payees", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_your_key_here",
    "Content-Type": "application/json",
    "Idempotency-Key": "create-payee-jane-001",
  },
  body: JSON.stringify({
    type: "individual",
    first_name: "Jane",
    last_name: "Smith",
    email: "jane@example.com",
    country: "GB",
    currency: "GBP",
    bank_account: {
      account_number: "12345678",
      sort_code: "123456",
    },
  }),
});

const { data } = await response.json();
console.log(data.id); // pye_cng3q8s...
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.dev/v1/payees",
    headers={
        "Authorization": "Bearer ak_test_your_key_here",
        "Idempotency-Key": "create-payee-jane-001",
    },
    json={
        "type": "individual",
        "first_name": "Jane",
        "last_name": "Smith",
        "email": "jane@example.com",
        "country": "GB",
        "currency": "GBP",
        "bank_account": {
            "account_number": "12345678",
            "sort_code": "123456",
        },
    },
)

payee = response.json()
print(payee["data"]["id"])  # pye_cng3q8s...
```

```go Go
body := strings.NewReader(`{
  "type": "individual",
  "first_name": "Jane",
  "last_name": "Smith",
  "email": "jane@example.com",
  "country": "GB",
  "currency": "GBP",
  "bank_account": {
    "account_number": "12345678",
    "sort_code": "123456"
  }
}`)

req, _ := http.NewRequest("POST", "https://api.antonpayments.dev/v1/payees", body)
req.Header.Set("Authorization", "Bearer ak_test_your_key_here")
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Idempotency-Key", "create-payee-jane-001")

resp, err := http.DefaultClient.Do(req)
```

</CodeGroup>

Save the `id` from the response -- you need it in the next step.

## Step 3: Create a payout

Send money to your payee. The payout goes through compliance screening and rail routing automatically.

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/payouts \
  -X POST \
  -H "Authorization: Bearer ak_test_your_key_here" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: payout-inv-1042" \
  -d '{
    "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
    "amount": "250.00",
    "currency": "GBP",
    "description": "Invoice #1042 payment",
    "reference": "INV-1042"
  }'
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/payouts", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_your_key_here",
    "Content-Type": "application/json",
    "Idempotency-Key": "payout-inv-1042",
  },
  body: JSON.stringify({
    payee_id: "pye_cng3q8s6ek9kc5qg1h1g",
    amount: "250.00",
    currency: "GBP",
    description: "Invoice #1042 payment",
    reference: "INV-1042",
  }),
});

const { data } = await response.json();
console.log(data.id);     // pay_cng3q8s...
console.log(data.status); // "created"
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.dev/v1/payouts",
    headers={
        "Authorization": "Bearer ak_test_your_key_here",
        "Idempotency-Key": "payout-inv-1042",
    },
    json={
        "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
        "amount": "250.00",
        "currency": "GBP",
        "description": "Invoice #1042 payment",
        "reference": "INV-1042",
    },
)

payout = response.json()
print(payout["data"]["id"])      # pay_cng3q8s...
print(payout["data"]["status"])  # "created"
```

```go Go
body := strings.NewReader(`{
  "payee_id": "pye_cng3q8s6ek9kc5qg1h1g",
  "amount": "250.00",
  "currency": "GBP",
  "description": "Invoice #1042 payment",
  "reference": "INV-1042"
}`)

req, _ := http.NewRequest("POST", "https://api.antonpayments.dev/v1/payouts", body)
req.Header.Set("Authorization", "Bearer ak_test_your_key_here")
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Idempotency-Key", "payout-inv-1042")

resp, err := http.DefaultClient.Do(req)
```

</CodeGroup>

The payout moves through these statuses:

```
created -> pending_screening -> processing -> sent -> completed
```

## Step 4: Track via webhooks

Polling works for testing, but production integrations should use webhooks. Register a webhook endpoint to receive real-time notifications on payout state changes.

<CodeGroup>

```bash cURL
curl https://api.antonpayments.dev/v1/webhooks \
  -X POST \
  -H "Authorization: Bearer ak_test_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-server.com/webhooks/anton",
    "events": ["payout.completed", "payout.failed", "payout.returned"]
  }'
```

```javascript Node.js
const response = await fetch("https://api.antonpayments.dev/v1/webhooks", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ak_test_your_key_here",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://your-server.com/webhooks/anton",
    events: ["payout.completed", "payout.failed", "payout.returned"],
  }),
});

const { data } = await response.json();
console.log(data.id); // wh_abc123...
```

```python Python
import requests

response = requests.post(
    "https://api.antonpayments.dev/v1/webhooks",
    headers={"Authorization": "Bearer ak_test_your_key_here"},
    json={
        "url": "https://your-server.com/webhooks/anton",
        "events": ["payout.completed", "payout.failed", "payout.returned"],
    },
)

webhook = response.json()
print(webhook["data"]["id"])  # wh_abc123...
```

```go Go
body := strings.NewReader(`{
  "url": "https://your-server.com/webhooks/anton",
  "events": ["payout.completed", "payout.failed", "payout.returned"]
}`)

req, _ := http.NewRequest("POST", "https://api.antonpayments.dev/v1/webhooks", body)
req.Header.Set("Authorization", "Bearer ak_test_your_key_here")
req.Header.Set("Content-Type", "application/json")

resp, err := http.DefaultClient.Do(req)
```

</CodeGroup>

You can also poll the payout status directly while testing:

```bash
curl https://api.antonpayments.dev/v1/payouts/pay_cng3q8s6ek9kc5qg1h2g \
  -H "Authorization: Bearer ak_test_your_key_here"
```

To list your recent payouts with cursor-based pagination:

```bash
curl "https://api.antonpayments.dev/v1/payouts?limit=10" \
  -H "Authorization: Bearer ak_test_your_key_here"
```

The response includes `has_more` and `next_cursor` fields. To fetch the next page, pass the cursor:

```bash
curl "https://api.antonpayments.dev/v1/payouts?limit=10&cursor=pay_def456" \
  -H "Authorization: Bearer ak_test_your_key_here"
```

<Tip>
  Webhooks are the recommended approach for production. Polling is acceptable during development, but webhook-driven architectures are more efficient and receive updates faster. See [Handle webhooks](/guides/handle-webhooks) for implementation details.
</Tip>
